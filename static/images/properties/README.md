These are sample photographs, not photographs of the listed Nepal properties.
The `replace_demo_images` command replaces only the original demo wallpaper
filenames. Preview with `python manage.py replace_demo_images`; apply with
`python manage.py replace_demo_images --apply`. Existing uploads are retained in
storage. Landlords can replace sample photographs with their own property photos.
